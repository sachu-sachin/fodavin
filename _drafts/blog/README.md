# Blog drafts (not published)

These posts are outlines with an intro only. They are kept out of the live site on purpose:
thin, unfinished posts can hurt rankings. Folders starting with `_` are not published by
GitHub Pages, and `_headers` marks `/_drafts/*` as `noindex` on Cloudflare Pages.

To publish a post: finish every `[TODO]`, then turn it into `/blog/<slug>/index.html` using a
service page as the layout, add `BlogPosting` (Article) JSON-LD with headline, datePublished,
author and publisher (`#organization`), link it from a `/blog/` listing page, and add it to
`sitemap.xml`.
