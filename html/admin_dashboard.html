The dashboard has no backend to talk to yet. Deploy the Apps Script and paste its URL into assets/js/fodavin-config.js.

  1. Create a Google Sheet, then Extensions → Apps Script.
  2. Paste the contents of backend/Code.gs and set ADMIN_PASSWORD.
  3. Deploy → New deployment → Web app; run as Me, access Anyone.
  4. Copy the /exec URL into formsEndpoint.

Full walkthrough in backend/README.md.
